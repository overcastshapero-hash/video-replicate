# 法律红线(必读)

复刻视频很容易在不知不觉中踩著作权、商标权、肖像权三条线。以下是本 skill 运行时必须遵守的硬规则。

## 可以做(思想表达层,不受版权保护)

- **叙事结构** — 几段、每段做什么、节奏快慢
- **镜头语言** — POV、低角度、推拉摇移、转场方式
- **整体视觉风格** — 色调、光照、画面氛围
- **主题创意的方向** — "拟人化海洋生物探险"这种类型化设定

## 不能做(表达层,受版权/商标/肖像保护)

- ❌ **logo / 水印** — 抖音、原 UP 主、品牌方水印一律不要,生成 prompt 里要把它们写进 `negative`
- ❌ **品牌名/标识** — 即使原片有"XX 公司""XX 产品",改编版必须替换或去掉
- ❌ **可识别人物面孔** — 真人肖像不能复刻;原片有真人就改成动物、卡通、抽象主体
- ❌ **原创音乐 / 人声** — 不要从原片提取音轨。BGM 用免版权库或生成,旁白用 TTS
- ❌ **特定 IP 形象** — 米老鼠、皮卡丘、明星形象、知名虚拟主播形象等

## 检测清单(质检阶段必查)

抽 `final.mp4` 关键帧,逐项确认:

- [ ] 画面任何位置无平台水印(角落、滚动字幕)
- [ ] 画面无可识别品牌 logo / 文字标识
- [ ] 无真人面孔与原片相似度过高
- [ ] 音轨独立生成,不含原片任何片段
- [ ] BGM 来源可追溯(免版权库或生成)

任一项不过关 → 标 ❌ 写入 `qc_report.md`,回 ④ 改 `negative` 后重生成。

## 用户想做盗版克隆时的回应

不绕弯子。直接说:

> "这个我不做。一比一克隆别人的视频,无论改不改主体,都可能侵犯著作权;原片有真人/品牌/水印的话还会叠上肖像权、商标权。我能帮你做的是结构和风格的复刻 + 你自己的主题,这一类目前在国内司法实践里通常被认为是'借鉴'而非'抄袭'。要这么做我们继续,不接受就到这。"

不要在用户坚持后让步。
