# 给小云雀的中文 brief 模板

> 这是 Director 角色第 ④ 段产出的关键文件。**不写英文 prompt、不拆分镜逐条提交**——一条中文 brief 一次提交,小云雀后端 agent 自己拆。

## 通用骨架

```
参考这个视频做一个【任务类型】。
保持原片的【保留要素列表】。
【主体改编要求 — 必须精确到外观差异】。
整片【画幅 + 时长】。
【配音字幕策略】。
不要【禁用清单】。
```

## 任务类型

- 结构复刻 demo  ← 截前 30 秒,验证质量
- 同款短片      ← 完整时长,主题保留
- 主题换皮      ← 完整时长,主题大改

## 保留要素

按重要性挑 3-5 个写:镜头节奏 / 构图 / 调色 / 氛围 / 转场风格 / 运镜方式 / 光照基调 / 视觉风格(电影感/手绘/动画/纪实)

## 主体改编要求(IP 避坑核心)

**必须给出 ≥ 2 个具体差异点**,否则小云雀可能直接照搬。

例:
- ❌ "换一个新机器人" — 太模糊
- ✅ "换一个不同头盔轮廓(方形圆角而非椭圆)、不同 LED 显示屏颜色(琥珀色而非蓝色)的新机器人"

## 画幅 + 时长

明确写,不留默认:
- "16:9 横屏 30 秒"
- "9:16 竖屏 跟原片同长"
- "切前 30 秒做 demo,16:9"

## 配音字幕策略(必写)

四选一:
1. "无人声配音,只要环境音"
2. "加中文 TTS 旁白,配字幕"
3. "保持原片节奏,有字幕"
4. "纯视觉,无字幕无声"

## 禁用清单

固定项 + 原片识别到的项:

固定:
- 原片水印
- 抖音 / B 站 / YouTube logo
- 真人面孔
- 任何识别到的品牌 logo

每片增量:
- 原作者署名(如"光续SAMA")
- 原片标题文字(如"ROBOT YAGO")
- 原片中出现的特定品牌产品

## 完整实例

### 例 1 — 机器人后启示录复刻 demo

> 参考这个视频做一个结构复刻 demo。保持原片的镜头节奏、构图、调色和后启示录电影感氛围,但人物形象要做差异化避开原 IP:原片机器人主角是创作者设计的特定角色,请换成一个不同头盔轮廓(方形圆角而非椭圆)、不同 LED 显示屏颜色(琥珀色而非蓝色)的新机器人。整片 16:9 横屏 30 秒,无人声配音,只要环境音(海浪、风、机械声)。不要任何字幕、原片水印、原作者署名"光续SAMA"、"ROBOT YAGO"字样、品牌 logo。

### 例 2 — 螃蟹换熊猫

> 参考这个视频做一条同款短片。保持原片的 POV 视角、低角度运镜、海滩调色和节奏。把主角从螃蟹换成一只熊猫(黑白毛、圆耳朵),其他场景元素(海滩、岩石、洞穴)保留。整片 9:16 竖屏,跟原片同长。无人声,只要环境音。不要原片水印和任何品牌名。

### 例 3 — 手绘解说类(长视频警告)

> 参考这个视频前 20 秒做一个开场复刻 demo。保持原片的 2D 手绘风格、节奏明快的切镜、文字标注方式。把主角"白蛋人"换成一个**线条更简洁的卡通圆头小人**(单色描边、表情用三个点)。整片 16:9 横屏 20 秒,有中文字幕(我会另给文案),无人声。不要"百变人生"作者署名、原片水印、原"白蛋人"形象。

## 实战硬化版(防结构跑偏 / 颜色漂移)

简单 brief 经常翻车在小云雀"为了画面好看而改变节奏/颜色"。硬化版加 4 段约束:

```markdown
本任务是【结构与节奏复刻】,最高优先级是严格保留原片镜头数量、时长比例、切换节奏和叙事顺序。任何为了画面"更好看"或更流畅而改变节奏、顺序或时长的行为都被视为失败。

【核心约束】
- 镜头顺序 100% 按原片时间顺序执行,不得重排、增减、合并
- 每个关键镜头时长比例偏差 ≤ ±15%
- 必须完整保留以下叙事/情绪链条:[填 3-5 个最核心连续镜头逻辑]

【主体差异化要求】
[主体] 必须做明显且可识别的差异化处理。具体要求 ≥ 2-3 条带禁止项:
- 例:"父亲上衣必须为浅色衬衫(接近米白或极浅灰),严禁出现任何偏棕、卡其或米黄色调。这是关键视觉锚点,100% 执行。"
- 例:"外套改为深蓝灰棉布夹克,头型改普通短发,禁止保留原片人物任何可识别面部特征。"

【视觉氛围保留】
整体保留:[从原片提取 2-3 个核心质感词,如"1990 年代中国乡村自然光 + 轻微胶片颗粒 + 温暖但不甜腻的纪实感"]。禁止商业电影化调色、光影美化、颗粒清理。

【严格禁用】
- 视觉禁用:原片人物可识别面孔、标志性服装细节、水印、平台 logo、作者署名、标题文字
- 行为禁用:原片人物的标志性动作模式

请基于参考素材直接生成最终视频,不要超出以上要求的创意发挥。
```

### 硬化版写完后 30 秒自检 checklist

- [ ] 最前面强声明"结构复刻"而非"创意生成"
- [ ] 明确写"镜头顺序 100% 保留" + 时长偏差控制
- [ ] 主体差异化具体到可执行 + 带禁止项(≥ 2-3 点)
- [ ] 同时写了视觉禁用和行为禁用
- [ ] 关键叙事链条被锁定
- [ ] 节奏较硬的原片加了反美化节奏指令

### 关键改进点(实战提炼)

- **"具体 + 禁止 + 强调锚点"** 比"模糊描述"对小云雀执行力提升明显
- 改进前:"浅色衬衫"
- 改进后:"浅色衬衫(接近米白或极浅灰),严禁出现任何偏棕、卡其或米黄色调。这是关键视觉锚点,100% 执行。"

需要更模块化的 prompt 组件,见 `xiaoyunque-structure-prompt-modules.md`(乐高式组合)。
