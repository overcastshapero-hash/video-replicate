## Prompt Factory 模式（结构复刻生产资料包）

**这是本项目目前最推荐的主力用法**。

核心理念：
- 视频结构复刻最难的部分不是「生成画面」，而是「把爆款的镜头节奏、叙事顺序、情绪曲线、构图逻辑」准确提取并翻译成可执行的指令。
- 这个 skill 把这套最难的工艺（经过风筝等真实项目打磨的 craft 框架 + 高级模板）固化下来，帮你产出**高质量、可直接用于任何视频/图像工具**的生产资料包。
- 生成视频这一步，完全交给你手头最好的工具（Kling、即梦、海螺、Luma、Runway、本地 ComfyUI、甚至 CapCut 模板），不再绑定小云雀。

### 什么时候用这个模式

- 你不想/不能依赖小云雀 credits
- 你想用目前最好的视频模型（经常比小云雀强）
- 你想批量实验同一个结构在不同工具上的效果
- 你想把「结构复刻方法论」沉淀成自己长期可复用的能力

### 你最终会拿到什么（核心资产）

跑完分析阶段后，工作目录里最有价值的是这几样（按重要性排序）：

1. `contact_sheet.jpg` — 所有镜头关键帧一览图（最直观的结构总览）
2. `scenes/scenes.json` + `scenes/frames/` — 精确切镜信息 + 每镜 head/mid/tail 三帧
3. `storyboard.json` — Claude 按工艺框架写出的结构化分镜表
4. `brief.md` — **最关键**：用《视频结构复刻工艺决策框架》+ 高级模板硬化后的中文 prompt 包

这四样组合在一起，就是目前能公开分享的最强「爆款视频结构复刻生产包」。

### 完整操作流程

1. 正常启动
   ```bash
   ./run.sh "https://v.douyin.com/xxxxxx/"
   ```
   （或手动走 download → clip_demo → split_scenes）

2. 让 Claude 写分镜和 brief
   - 切换到 Director + Storyboard Critic 角色
   - 基于 contact_sheet + 帧写 `storyboard.json` 和 `brief.md`
   - **会自动使用我们同步进来的高级模板**（这是质量保障）

3. 查看当前状态
   ```bash
   bash scripts/next.sh <WORKDIR>
   ```

4. 当看到 `brief.md` 已生成，且 next.sh 同时列出两条路径时，**可以选择停止**。

5. 直接使用生产包
   - 把 `brief.md` 完整内容 + 对应关键帧，扔给 Kling / 即梦 / 海螺 等做图生视频或文生视频
   - 用 `scenes/frames/` 做精确的 Image-to-Video 参考
   - 按 `storyboard.json` 里的时长和顺序自己后期拼接
   - 需要横/竖屏自动拼接时，依然可以用 `bash scripts/compose.sh <WORKDIR>`

### brief.md 质量保障（为什么这个包特别强）

我们把真实项目打磨出来的硬化技巧固化在模板里：

- 必须在最前面强声明「结构与节奏复刻」
- 镜头顺序 100% 保留 + 时长偏差控制在 ±15%
- 主体差异化必须具体 + 带禁止项（颜色、形状、材质锚点）
- 同时写视觉禁用 + 行为禁用
- 反美化节奏指令（防止小云雀/Kling 把硬节奏拍成电影感）

这些技巧来自风筝等项目真实失败复盘，极大降低了「画面好看但结构跑偏」的概率。

### 与原有小云雀路径的关系

- 两个路径**完全并存**，不会互相影响。
- `next.sh` 在 brief 阶段会同时展示两条路，你随时可以决定走哪条。
- 想一键出片就继续走小云雀；想用更好工具或省 credits，就停在这里拿包。
- 所有原有脚本（xyq_*、run.sh 对小云雀的支持）全部保留且不受影响。

### 推荐工具搭配（2026 年 5 月现状参考）

- **追求最高质量**：Kling 2.0 / 即梦 3.0 + 精确关键帧控制
- **性价比高**：海螺 / Luma Dream Machine
- **本地可控**：ComfyUI + AnimateDiff / DynamiCrafter + IP-Adapter
- **快速验证**：CapCut 模板 + 手动拼

### 常见问题

**Q: 这个模式还能不能保证结构 100% 准确？**
A: 结构准确度主要由 prompt 包决定。只要你把 `brief.md` + 关键帧用好，结构忠实度通常比直接扔原视频给模型要高很多。

**Q: 后期拼接麻烦吗？**
A: 不麻烦。`compose.sh` 依然可用，且不依赖小云雀。或者直接用剪映/Pr 按 storyboard.json 里的时长拼。

**Q: 想以后再走小云雀怎么办？**
A: 随时可以。生产包里的 `brief.md` 本身就是高质量的，直接扔给小云雀 submit 也完全没问题。

### 总结

这个模式把「视频结构复刻」这件事里最有价值、最难标准化的部分（工艺 + prompt 工程）做成了可 clone、可复用的工具。
生成画面这件事，交给你当前能拿到的最好工具。

这是目前把这个项目做成「高质量内部工具公开版」后的推荐主力用法。
