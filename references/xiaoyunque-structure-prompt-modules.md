# Xiaoyunque 结构复刻 Prompt 模块包（基于工艺框架）

这些模块是从《视频结构复刻工艺决策框架》提炼出的可直接复用的 prompt 组件。目标是让给小云雀的 brief 更硬、更精准，减少结构跑偏。

---

## 核心原则
- 结构复刻 > 画面好看
- 具体约束 > 模糊描述
- 禁止项往往比“要做什么”更有效
- 必须反复强调“不要为了美观而改变节奏”

---

## 推荐模块（按优先级）

### 1. 任务类型强声明（几乎必加，开头用）
```
本任务是【结构与节奏复刻】，而非创意生成或风格迁移。
最高优先级是严格保留原片镜头数量、时长比例、切换节奏和叙事顺序。
任何为了画面“更好看”或更流畅而改变节奏、顺序或时长的行为都被视为失败。
```

### 2. 结构锁定模块（核心）
```
镜头顺序必须100%按照参考素材的时间顺序执行，不得重新排列、增减或合并任何镜头。
关键转折点的时长比例偏差必须控制在±15%以内。
```

### 3. 叙事链条锁定（针对有明显叙事脉络的视频）
```
必须完整保留以下叙事/情绪链条：[在此列出最核心的3-5个连续镜头逻辑关系]，这是结构的核心，不可打断或重新组织。
```

### 4. 主体差异化强化模块（必须具体 + 带禁止）
格式模板：
```
[主体名称]必须进行明显且可识别的差异化处理。
具体要求：[列出2-3个可执行的外观差异]。
严禁保留原片任何标志性外貌特征、服装轮廓或动作习惯。
```

示例（风筝项目）：
```
父亲上衣必须为浅色衬衫（接近米白或极浅灰），严禁出现任何偏棕、卡其或米黄色调。这是主体差异化的关键视觉锚点，必须100%执行。
```

### 5. 反美化节奏模块（节奏较硬的视频强烈建议）
```
严格保持原片生硬、直接的切换感。不要为了画面流畅、美观或“电影感”而延长任何镜头、柔化转场或进行节奏美化。
```

### 6. 氛围质感锚定模块
```
整体视觉风格必须保留：[从原片提取的2-3个核心质感词]。
禁止进行商业电影化调色、光影美化或颗粒感清理。
```

### 7. 禁用清单模块（视觉 + 行为）
```
视觉禁用：原片人物可识别面孔、原片标志性服装细节、原片水印、平台logo、作者署名、标题文字。
行为禁用：原片中人物的标志性动作模式。
```

---

## 使用建议

**最小可用组合（推荐新手每次都用）：**
1 + 2 + 4 + 7

**高质量组合（推荐认真做视频时使用）：**
1 + 2 + 3 + 4 + 5 + 6 + 7

把这些模块当成乐高，根据每条视频的特点自由组合，比每次都从零写一段模糊描述效果好得多。
